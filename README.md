# 🛍️ Shopy

A modern E-Commerce web application built with **HTML, CSS, JavaScript**.  
Shopy provides a clean shopping experience with authentication, product browsing, search, categories, cart management, and order tracking.

---

## ✨ Features

- 🔐 User Authentication
  - Login
  - Sign Up

- 🛒 Shopping Cart
  - Add products to cart
  - Remove products
  - Cart total calculation

- 🏪 Product Store
  - Browse all products
  - Product details
  - Responsive product cards
  - Filter products by category

- 🔍 Search
  - Search products by name

- 📦 Orders
  - View previous orders
  - Order history

- 📱 Responsive Design
  - Works on Desktop, Tablet, and Mobile

---

## 🚀 Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- DummyJSON API (Currently)
